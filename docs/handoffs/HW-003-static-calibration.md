真值來自使用者的固定量測位置，在確認不移動的時間窗內以 0.1 s 間距展開，供既有 evaluate-run.py 的 0.25 s 對齊使用。這是固定位置真值，**不是獨立追蹤感測器量測**；位置量測不確定度未提供。skipped_unmatched=0，truth_used_by_solver=false。

只有一個靜態擺放與一趟任務，43 筆不是 43 場獨立實驗，濾波後樣本也可能相關。數字僅代表該段未校正、條件於有效解的水平誤差，不外推成移動巡查、其他場景或整體精度。

未事先建立固定評估格點，因此正式定位成功率不報。初次診斷將取得快照數當作分母的結果已保留為 initial-diagnostic 並更正為未提供；誤差表的有效樣本與位置誤差未改。未量測延遲或封包遺失率。

實際 RPi 未移動時，估計位置抖動仍可能形成第二階段使用的幾何基線，使 Target 顯示 valid；這是 ISSUE-021。此狀態不當作真實移動觀測完成的證據，正式轉折巡查另驗。

三維距離依已知高度計算，校正資料只使用收到的 RSSI 與已知距離，不使用估計位置反推距離。後續校正遵循 calibrate-rssi.py 的樣本／距離範圍與 n 合理性檢查，不靠單點調參宣稱精度改善。

第三點每設備 31–33 個去重觀測。合併三點後，四 Anchor 已達距離跨度要求，但 T01=1.680、T02=1.970，仍不足。A01 最小平方法擬合 n≈−0.155，calibrate-rssi.py 實際拒絕並未產生校正檔。其他三 Anchor 的診斷 n 約為 A02=2.528、A03=4.966、A04=1.907，僅作診斷，尚未部署。

第四點建議靠近 A01，用近距離資料檢查該設備的不一致，同時增加兩 Target 的遠距離範圍；以使用者實際回報位置與高度為準。每點採完會結束該校正巡查，避免移動期間混入本點樣本。高度改變會保存為新巡查，Anchor／Target 設定不變。

若第一點納入校正訓練，後續校正效果須用新的保留位置或另一次實驗驗證，不能以訓練點重算誤差作獨立改善證據。Target 與四 Anchor 全程保持固定；T02 斷電測試先保留待辦。
