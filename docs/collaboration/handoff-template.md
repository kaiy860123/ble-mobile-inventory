# 任務交接格式

```text
任務 ID／標題：
交付者／審查者：
狀態：todo / in_progress / ready_for_review / blocked
基準 commit：
工作分支／交付 commit：

需求與驗收：
允許修改範圍：
實際修改檔案：
介面或資料格式影響：

測試環境／版本：
執行命令：
預期／實際結果：
證據（TEST、ISSUE、run_id、檔案／CI）：
未執行項目及原因：

問題重現與修正：
剩餘限制／阻塞：
合併注意事項：
部署與還原方式：
報告／進度需更新處：
下一個具體動作：
```

交接中不放帳密、私鑰或個人帳號截圖。以可重現的結果取代「應該可用」。

目前共用資料夾：完成所有交付內容後，最後將狀態改為 `ready_for_review`，列明交付檔案並暫停編輯。Codex 排程會偵測變更並依 `auto-review.md` 審查；再次修改前改回 `in_progress`。審查不需要另外貼訊息啟動。
