## 每次交付的檢查

依受影響範圍執行 `python -m pytest -q`、`npm test`、`npm run build`。韌體有改再執行對應 PlatformIO environments；只改報告不為計算進度而重跑所有硬體流程。

合併後由 Codex 再檢查整合版本，沿用既有 CI。測試失敗先建立 ISSUE 與最小重現，修正後記重測。人工測試記錄實際操作者、版本、步驟、預期／實際與證據；沒有執行就標未執行。

## 實驗最小設計

- 校正與評估分開；測試 Target 水平真值只進評估檔。
- 建議至少三次不同巡查路徑／Target 擺放的獨立任務；這是待執行計畫，不是已取得樣本數。
- 比較固定濾波參數與基準版本時使用相同觀測，另以新實驗檢查泛化。
- 報告同時列定位成功率、樣本／任務數、RMSE、P50／P95、盤點召回率與時間；未取得資料則保留待測。
- 測試兩個 Target 中途關閉一個、Anchor 不足、網路中斷、無地理參考與舊資料狀態。
