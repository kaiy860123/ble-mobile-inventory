## 實驗固定條件

先固定天線方向、RPi 高度、模型與濾波，六個 Anchor 同時錄製，再用同一份原始觀測選 A01–A04 或 A01–A06 重播。這能控制收訊與路徑差異；它比較的是給定六設備錄製條件下的 Anchor 子集效果，並不獨立量測額外廣播造成的無線競爭效應。

新增位置先前僅建議 A05 約 (0,3.8)、A06 約 (0,1.9)，尚未確認可放置或量測；不能直接寫入 measured 設定。既有 RPi 量測座標、原 RSSI 模型、高度及歷史均保留。先識別兩塊備品、逐塊刷入與解碼，再依實測座標使用設定交易擴充名單。

校正訓練、選參與正式評估分開。上輪四點候選已因有效解減少回退，不將其混入 Anchor 數量比較。若後續開發品質加權或新的校正，另以相同資料作第二組實驗，並用新保留資料驗證，不能以答案選最佳參數後又當獨立測試。

## 驗收門檻

1. 無 A05／A06 真實觀測時拒絕產生「六 Anchor 實測改善」結果。原始 schema、來源、scanner、時序及設定先校驗；不得只驗證過濾後的批次而藏掉錯誤。
2. 分別列 RPi／Target、各自有效樣本與共同有效樣本，RMSE、P50／P95；沒有移動 RPi 真值就不報其誤差。Target 真值不送求解器。
3. 正式定位成功率在錄製前固定評估時點與可接受資料新鮮度；不得把批數或取得快照數事後當分母。增加有效解與降低誤差都需檢查。
4. 保留原始資料、冷啟動重播、來源／版本／SHA256。不夾位置到室內範圍、不放寬有效門檻讓結果看似改善。
5. 新保留位置與至少三條不同轉折路徑為待執行計畫。先列結果再決定採用，不預設六 Anchor 一定較準。
